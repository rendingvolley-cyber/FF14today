# FF14 Today v1.1 UI direction

- Light-first visual language. No dark theme for the primary planner surface.
- One accent color: clear sky blue.
- The first screen should answer only: “How do I feel like playing today?”
- Keep character sync compact; it is infrastructure, not the hero.
- Hide development roadmap from the user-facing screen.
- Achievement and job progress become secondary/collapsible information.
- Mode choices are large, airy entry cards rather than dense segmented controls.
- Recommendation #1 is visually primary, #2/#3 are quieter stacked alternatives.
- Every recommendation must expose purpose, why-now, and first step without requiring the user to decide missing details.
- Mobile layout is single-column with generous spacing and no horizontal compression.
